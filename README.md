# FFWPU-SA

A full-stack, responsive community web application that enables registered members to connect, manage events, and communicate in real time.

## Features
- Member profiles with guided onboarding and search
- Admin-created events with RSVPs and calendar-friendly views
- Real-time messaging using Socket.io
- Admin dashboard with role-based access and database policies

## Tech Stack
- Frontend: React + TypeScript (Vite), Tailwind CSS
- Backend/Services: Supabase (Auth, Database, Functions)
- Realtime: Socket.io

## Getting Started
1. Clone the repository:  
   `git clone https://github.com/yourusername/FFWPU-SA.git`
2. Install dependencies:  
   `npm install`
3. Configure environment variables by creating a `.env` file using the provided example and adding your Supabase project keys.
4. Run the app:  
   `npm run dev`

## Project Status
